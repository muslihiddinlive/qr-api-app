API qanday ishlaydi

Bitta GET so'rov — javob to'g'ridan-to'g'ri rasm bo'lib qaytadi. Telegram bot buni sendPhotoga URL sifatida to'g'ridan-to'g'ri bera oladi.

GET https://qr-api.example.workers.dev/qr?text=https://t.me/username&size=300&format=png
ParametrMajburiymiIzoh
textHaQR ichiga yoziladigan matn yoki havola
sizeYo'qPiksellarda, 64–1024 (standart: 300)
formatYo'qpng yoki svg (standart: png)
marginYo'qChetdagi bo'sh joy, 0–10 (standart: 2)
logo_urlYo'qMarkazga qo'yiladigan logotip PNG rasmining ochiq linki
logo_sizeYo'q0.1–0.2 oralig'ida, QR o'lchamiga nisbatan (standart: 0.2). Skanerlanishi ishonchli bo'lishi uchun chegaralangan

await bot.send_photo(
